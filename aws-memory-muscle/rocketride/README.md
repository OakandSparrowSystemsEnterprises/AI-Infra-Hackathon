# RocketRide Event Surface

Create the functional `.pipe` here after the event build period opens.

The first pipeline should stay deliberately small: operator input → coding agent → Cognee memory → HydraDB durable context → Hotdata live state → Tenki execution tool → evidence normalization → Gatekeeper request tool → controlled effect → learning writeback.

Do not expose a raw GitHub write tool directly to the main agent. The write-capable effect should sit behind the governed-effect boundary.

Do not create the working `.pipe` before build open. `main.pipe.EVENT_CREATE` is a marker, not a pipeline.
