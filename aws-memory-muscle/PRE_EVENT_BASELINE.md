# Pre-Event Baseline and IP Boundary

Recorded before the September 11, 2026 AWS Data & AI Hackathon build period.

## Preexisting OASSE technology

Gatekeeper V2 / V2-NPU is preexisting Oak & Sparrow Systems Enterprise LLC technology. Its authority engine, policy corpus, proprietary source, private infrastructure, credentials, controlled actuators, receipt internals, patents, patent applications, and trade secrets are not included in this hackathon tree and are not licensed by it.

The hackathon application may call Gatekeeper only through an external interface. Gatekeeper remains the sole execution-authority source and returns the existing OASSE semantics ALLOW, TRANSFORM, HOLD, or DENY.

The architecture pattern gateway → authority → worker, worker isolation, exact-action binding, fail-closed behavior, controlled-effect separation, and non-authoritative sponsor planes are preexisting OASSE architecture derived from prior Gatekeeper V2-NPU and agent-native validation work.

This tree contains setup scaffolding, architecture, contracts, schemas, environment placeholders, acceptance tests, adapter interfaces, operator notes, and build-order planning only.

It contains no functional sponsor integration, no working RocketRide `.pipe`, no coding-agent remediation logic, no live Tenki execution flow, no Snyk automation, no Rote Play, no hackathon-specific Gatekeeper adapter, no GitHub write actuator, and no judge-facing application behavior.
